# Aurabot 改进方案与现状梳理（2026-11-18）

## 核心原则

1. **维持「大小脑机制」**：
   - **小脑**（`autonomy` / `bili` 等后台轻决策）：结合时间、天气、记忆、最近做过的事走 AI 决策树，路由这一轮做什么。
   - **大脑**（主会话 `hub`）：带着完整人设与对话上下文真正开口说话、决定语气、是否发 `<voice>` 或 `[沉默]`。
2. **代码只守底线与修 Bug，不替她说话**：
   - 删掉强行接管表达的硬逻辑（如 15% 随机变语音），修复真正的机制 Bug 和平台缺陷（如 `[沉默]` 扣额度、卡死状态、空消息记录、重复 `@`）。
   - 行为习惯与节奏偏向通过**完整背景信息 + 侧面提示词引导 + 人设卡**发挥模型能动性，保留活人感。
